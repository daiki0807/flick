# フリック入力キーボード

`index.html` だけで動く日本語入力アプリです。ブラウザで開くか、ローカルサーバーで利用できます。

## 編集と変換

- 入力欄をタップしてカーソルを置き、フリック入力すると、その位置に文字を挿入します。
- 文字を選択して入力すると、選んだ範囲を置き換えます。「さくじょ」は選択範囲、またはカーソルの直前の1文字を削除します。
- 「◀」「▶」でカーソルを移動できます。濁点・半濁点・小文字も、カーソルの直前か選択した1文字に作用します。
- 入力欄の下に変換する読みが表示されます。その範囲の外へカーソルを動かすと、読みをかなのまま確定します。
- 漢字候補を選ぶと、その読みだけを変換します。長い読みが複数区間に分かれた場合、残りの読みについて候補を続けて取得します。
- 通信失敗時は読みを保持し、候補の再取得ボタンを表示します。かなのまま確定することもできます。
- 直接入力・ペーストは通常の文章として扱い、フリックの変換対象とは分けて確定します。

## キーの配置

「キーの配置」で切り替えます。初回は従来の5列配置です。選択した配置だけをブラウザ内に保存します。

| 配置 | あ行の方向 |
| --- | --- |
| 今の配置（5列） | 中央あ・上い・右う・下え・左お |
| スマホ型（3列） | 中央あ・左い・上う・右え・下お |

スマホ型の「や」は上ゆ・下よ、「わ」は左を・上ん・右ーです。専用の「゛゜」「小」キーと、操作ボタンの「ー」はどちらの配置でも利用できます。

## タブレットの画面

- 横向きのタブレットでは、左に文章と変換候補、右にキーを並べます。縦向きでは上に文章、下にキーを置きます。
- 画面の高さに合わせて入力欄とキーの大きさを調整し、通常のタブレット画面ではページ全体をスクロールせずに入力できます。
- 長文は白い入力欄の中だけでスクロールします。変換候補は横にスクロールでき、候補の増減でキーの位置が動きません。
- コピー・保存・検索・クリア・操作説明は右上の「メニュー」にまとめています。メニューを開いても入力欄やキーの位置は変わりません。
- 高さが640px未満の短い縦向き画面では、操作が隠れないようページのスクロールを許可します。

## 動作確認

追加パッケージのインストールは不要です。Node.jsで入力処理と通信の回帰テストを実行できます。

```sh
node --test tests/editor.test.cjs
```

ブラウザで確認する場合は次のコマンドでサーバーを起動し、`http://127.0.0.1:18880/index.html` を開きます。

```sh
python3 -m http.server 18880 --bind 127.0.0.1
```

漢字候補はGoogleの変換サービスへ読みを送信して取得するため、インターネット接続が必要です。候補が届く順番にかかわらず、現在の読みだけを表示します。
